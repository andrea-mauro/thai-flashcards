# 🇹🇭 Thai Flashcards

A lightweight web application for learning Thai vocabulary and phrases. Features category filtering, progress tracking, quizzes for numbers, time, and days/months, and text-to-speech audio.

## 📁 Project Structure

- `src/` — TypeScript source code
  - `app.ts` — main application entry point
  - `utils.ts` — shared utilities (audio, toast)
  - `types.ts` — shared TypeScript interfaces
  - `modules/` — feature modules (`flashcards.ts`, `numbers.ts`, `time.ts`, `days.ts`, `tones.ts`)
  - `data/` — vocabulary dataset
  - `css/` — modular stylesheets
- `tests/` — unit and e2e tests
- `docs/` — build output (gitignored, generated by `npm run build`)

## 🏆 Scoring & Progress

The app features a **Mastered Flashcards** system:
- **Marking Cards:** Click the checkmark icon on any card to mark it as mastered.
- **Progress Tracking:** A real-time counter in the stats bar shows your mastered words for the current category.
- **Persistence:** Progress is saved in `localStorage` and persists across sessions.

## 🛠️ Data Management

The vocabulary dataset uses **UUIDs** for unique identification, which means:
- **Easy Expansion:** Add new words anywhere without worrying about ID conflicts.
- **Stable Progress:** Persistence relies on UUIDs, so your progress survives dataset updates.

## 🚀 Local Development

```bash
npm install
npm start        # Vite dev server
npm run build    # Production build → docs/
npm run serve    # Build + preview at localhost:5566
```

## 🧪 Testing

```bash
npm run test:unit          # Jest unit tests
npm run test:e2e           # Cypress e2e tests (requires build)
npm run test:e2e:open      # Cypress interactive mode
```

Tests run automatically on pull requests via GitHub Actions.

## 🌐 Deployment

Deployed automatically to **GitHub Pages** via GitHub Actions on every push to `main`. The workflow builds the project with Vite and uploads the output directly.

## 🔊 Audio Support

The app uses the **Web Speech API**.
- **Desktop:** Works automatically in most modern browsers.
- **Mobile:** Ensure you have a Thai voice downloaded in your phone's system settings (usually under Accessibility > Spoken Content or Language settings).
